# Copy revision 2.0.1

The project owner flagged the method heading and paragraph as overly generic and promotional. This revision replaces the marked text and analogous passages with descriptions of the materials, actions and limits involved. The chapter structure and visual layout are retained.

Examples:

| Previous wording | Revised wording |
| --- | --- |
| 每一条线，都有来处。 | 资料来源与证据范围 |
| 让来源、推定和缺口一起被看见。 | 点击地图连线或网络节点，可查阅相应的来源与证据说明。尚未核实的中转地点和单件文献对应关系，不作确定标注。 |
| 网络塑造了人们认识它们的方式。 | 地图记录材料在地点之间的流转，网络记录相关人物、机构与事件。 |

| A message first. A transfer later. | Qing government: telegram and transfer |

Both language versions describe the same underlying records. The six timeline headings use plain display labels, while the exported research snapshot retains its original metadata. No historical dates, source references, evidence records, graph relations or route geometry have been changed.

For future edits, name the action or material before making an interpretive claim. Keep distinctions such as transport versus accession and batch versus individual manuscript, but explain them through the relevant records rather than repeating slogan-like headings. Do not claim that all links have equally strong evidence or that the project reconstructs every manuscript’s custody history.
